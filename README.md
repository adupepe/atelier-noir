# Atelier Noir

Minimalistyczna, responsywna strona restauracji fine dining.

## Uruchomienie

Otwórz plik `index.html` w przeglądarce. Strona nie wymaga instalowania
zależności ani uruchamiania serwera.

## Zawartość

- responsywny układ na komputer i telefon,
- autorskie zdjęcia dań,
- menu degustacyjne,
- formularz rezerwacji w wersji demonstracyjnej,
- subtelne animacje i mobilna nawigacja.
